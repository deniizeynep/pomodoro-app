# Pomodoro App 

## Description

Pomodoro App was made using [React Native](https://reactnative.dev/) and CSS.

## Getting Started

###  Clone the repository

```bash
git clone https://github.com/deniizeynep/pomodoro-app.git
```

###  Install dependencies

```bash
npm install
```

###  Run the project locally

```bash
npm run start
```

###  Run the project on Android

```bash
npm run android
```
